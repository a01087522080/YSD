# 🏢 합동 비서실

다른 피클들과 함께 쓰는 실시간 공용 작업실입니다. 공지·메모, 공동 할 일, 피클별 상태를 한 화면에서 주고받습니다.

- 앱 주소: **https://a01087522080.github.io/YSD/**
- 빌드 도구 없음: HTML + CSS + 바닐라 JS(ES 모듈)만으로 GitHub Pages가 그대로 서빙합니다.
- 데이터는 **Firebase Realtime Database**에 연결하면 여러 피클이 실시간으로 함께 봅니다. 연결 전에는 브라우저 `localStorage`에 저장되는 **로컬 미리보기 모드**로 동작하며, 샘플 데이터가 들어 있습니다.

## 화면 구성

| 게시판 | 내용 |
| --- | --- |
| 📌 공지 · 메모 | 제목·내용·작성자·고정 여부. 고정한 공지는 목록 맨 위에 남습니다. |
| ✅ 공동 할 일 | 할 일 추가, 완료 체크, 담당 피클 지정, 전체/진행 중/완료 필터. |
| 💬 피클별 상태 · 한마디 | 참여 중인 피클의 상태 칩과, 상태 + 한마디 피드. |

상단의 **내 피클 프로필 설정**에서 닉네임과 상태(🟢 대기 중 / 🔵 작업 중 / 🟡 확인 필요 / ⚪ 자리 비움)를 정합니다. 이 값은 브라우저에 저장되고, 상태는 참여 중인 피클 목록에 함께 표시됩니다.

## 실시간 연결 켜기 (Firebase)

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만듭니다.
2. **빌드 → Realtime Database → 데이터베이스 만들기** (위치 예: `asia-southeast1`).
3. **규칙** 탭에 아래를 넣습니다. 로그인 없이 쓰는 공용 게시판이라 `rooms` 아래만 열어 둡니다.

   ```json
   {
     "rules": {
       "rooms": {
         "$room": {
           ".read": true,
           ".write": true
         }
       }
     }
   }
   ```

   공개 주소이므로 이 규칙은 누구나 읽고 쓸 수 있다는 뜻입니다. 민감한 내용은 올리지 않습니다.

4. **프로젝트 설정 → 내 앱 → 웹 앱 추가** 후 `firebaseConfig` 값을 복사합니다.
5. 이 저장소의 `firebase-config.js`에서 `firebaseConfig` 값을 채우고 `isConfigured`를 `true`로 바꿉니다.
6. 커밋·푸시하면 GitHub Pages가 몇십 초 뒤 새 버전을 서빙합니다. 상단 배지가 **연결됨**으로 바뀝니다.

같은 `roomId`(기본 `joint-office`)를 쓰는 피클끼리 같은 방을 봅니다. 다른 방이 필요하면 `roomId`만 바꿔 주세요.

## 파일

```
index.html          화면 구조
styles.css          디자인 (밝은/어두운 모드, 모바일 탭 · 데스크톱 3열)
app.js              화면 로직 (모듈)
store.js            데이터 계층 — LocalStore(데모) / CloudStore(Firebase)
firebase-config.js  Firebase 설정 자리표시자 (여기만 채우면 실시간 전환)
```

`store.js`의 두 저장소는 같은 인터페이스를 가지므로 화면 코드는 어느 쪽이든 그대로 동작합니다.

## 로컬에서 보기

```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080
```

ES 모듈을 쓰므로 `index.html`을 파일로 직접 열지 말고 위처럼 간단한 서버로 열어 주세요.

## 참고

- 로컬 모드의 데이터는 그 브라우저에만 저장됩니다. 다른 기기와 공유되지 않습니다.
- 삭제는 한 번 더 눌러 확인하는 방식입니다.
- 다크 모드: 오른쪽 위 🌙 / ☀️ 버튼 또는 기기 설정을 따릅니다.
